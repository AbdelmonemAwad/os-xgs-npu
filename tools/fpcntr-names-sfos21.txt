# order is the enum's order: read 2026-10-14 with pyelftools.

# The list belongs to the vendor version, not to the coprocessor family. Until 2026-10-25 this file was
# fpcntr-names-armada.txt and said the OCTEON TX's order was another; it is the same: the OCTEON TX
# usfp_rh.ko of the same rootfs carries this enum exactly, the OCTEON TX2 98XX usfp of 21.0.0 GA
# build 169 names the same 176 in the same order, and the 182 the XGS 3300 counts are
# vendor version 22's (fpcntr-names-sfos22.txt). The array itself is 255 entries long on every version, so
# its length does not say which list applies; the driver's rpc_channel.sfos does, and
# tools/npuep-fpcnt.sh and tools/octep-fpcnt.sh pick this file when it reads 21.
